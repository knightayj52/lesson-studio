Lesson Studio 개인정보 처리 안내

프로젝트와 수업 자료

프로젝트 JSON과 보관을 선택한 출력 파일은 사용자의 Google Drive에 저장됩니다. 앱은 drive.file 권한으로 앱에서 생성하거나 연결한 파일을 조회하고 저장합니다. 사용자는 Drive에서 파일을 삭제하고 휴지통을 비울 수 있습니다.

교육과정 조회

‘원본 연결’을 누르면 별도의 Google Sheets 읽기 전용 권한을 요청합니다. 앱은 지정된 교육과정 시트 세 탭을 읽습니다. 검색 자료는 브라우저 메모리에 두고 직접 연결한 행과 조회 시점은 프로젝트에 저장합니다. 연결 해제 시 조회 목록을 지웁니다.

설계서와 AI

PDF·DOCX·JSON·텍스트 가져오기와 기본 자료 생성은 브라우저에서 처리합니다. Gemini 모델 조회 시 입력한 키를 Google에 전송합니다. ‘초안 요청’을 누르면 단원 설계, 학년·과목, 수업 모형, 연결 기준과 선택한 차시 내용이 Google Gemini로 전송됩니다. 학생 이름과 개인을 식별할 수 있는 자료를 제외하세요. AI 서비스의 데이터 처리는 해당 계정의 Google 약관과 설정을 따릅니다.

연결 해제와 삭제

API 키와 인증 토큰은 실행 중인 브라우저 메모리에서 사용합니다. 앱이 생성하는 프로젝트와 출력 파일에는 인증 정보를 기록하지 않습니다. 연결 해제는 브라우저의 작업 상태를 비우며 보관한 파일은 Drive에서 직접 관리할 수 있습니다. Google 계정의 타사 앱 연결 설정에서 권한을 철회할 수 있습니다.

운영 상태

교사용 테스트 버전입니다. 정식 운영 전 운영자 문의처와 개인정보 처리 절차 및 OAuth 공개 상태를 확정할 예정입니다.
