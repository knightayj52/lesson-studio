01 / PROJECT BRIEF

수업 프로젝트 개요

기존 설계를 가져오거나 새 수업의 기본 정보를 정리하세요.

TXT·MD 설계 텍스트 또는 Lesson Studio JSON 파일을 가져올 수 있습니다. PDF·DOCX 가져오기는 아직 지원하지 않습니다.

02 / LESSON MAP

차시별 구성

단원 전체의 수업 흐름을 정리하세요. 각 차시의 제목과 상세 설계를 개별 관리합니다.

차시 구성은 프로젝트 저장 파일에 함께 보관됩니다.

03 / CURRICULUM

교육과정 연결

성취기준 원문을 확인해 프로젝트에 연결합니다.

공통 교육과정 데이터관리자 원본: 초·중·고 2,228개 기준. 자동 갱신 API는 아직 연결되지 않았습니다. 기존 스프레드시트 공개 범위는 변경하지 않았습니다.
04 / RESOURCE STUDIO

수업 자료 제작

차시 설계를 기준으로 제작할 자료 유형을 선택할 수 있도록 구성했습니다. 아래 기능은 제작 엔진 연동 전 준비 상태입니다.
