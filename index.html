수업 준비는 더 간편하게,
배움의 설계는 더 깊게.

단원과 차시별 수업을 정리하고, 나만의 수업 자료를 쌓아가는 교사용 작업실입니다.
프로젝트는 선생님 본인의 Google Drive 에 저장됩니다.

프로젝트는 앱 전용 Drive 파일 권한으로 저장합니다. 교육과정 조회 시 별도로 Sheets 읽기 권한을 요청합니다.

03 수업 자료 제작 수업 자료 미리보기와 출력

01 / PROJECT BRIEF

수업 프로젝트 개요

기존 설계를 가져오거나 새 수업의 기본 정보를 정리하세요.

PDF(텍스트형)·DOCX·TXT·MD 또는 Lesson Studio JSON을 가져올 수 있습니다. 최대 5MB입니다.

학교급별 수업 예시 열기

가상 관찰·조사 자료로 만든 차시를 열어 여섯 가지 출력물을 비교할 수 있습니다.

설계서에서 차시 찾기

“1차시”, “2차시”로 시작하는 줄을 기준으로 제목과 내용을 추출합니다.

02 / LESSON MAP

차시별 구성

단원 전체의 수업 흐름을 정리하세요. 각 차시의 제목과 상세 설계를 개별 관리합니다.

차시 구성은 프로젝트 저장 파일에 함께 보관됩니다.

03 / CURRICULUM

교육과정 연결

성취기준 원문을 확인해 프로젝트에 연결합니다.

원본 열람 권한이 있는 계정으로 연결하세요.
04 / RESOURCE STUDIO

수업 자료 제작

차시의 목표와 질문을 정하고 활동별 자료를 확인하세요.

Gemini로 차시 설계 초안 작성

선택한 차시·단원 설계·연결 기준을 Google Gemini로 전송합니다. 학생 개인정보를 제외하세요.
