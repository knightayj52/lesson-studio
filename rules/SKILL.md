# Lesson Studio v1.0
## 원본 및 갱신
원본은 https://docs.google.com/spreadsheets/d/1gK6KWo-Zuco0aDnW-bP4BTPo3u76Ku_TSNSd9fINEAU/edit 이다. 매 작업 시작 시 연결된 Google Sheets 도구로 메타데이터와 필요한 최신 범위를 읽는다. 전체 탭 A:K의 헤더로 필드를 매핑하고 실제 마지막 데이터까지 확인한다. 행 위치가 아니라 학년군·교과·과목·코드로 식별한다. 교과 탭보다 전체 탭을 우선한다. 전략은행 및 통합교과단원은 필요할 때 최신 행을 읽는다. 읽기 실패 시 마지막 스냅샷의 날짜를 밝히고 최신이라고 주장하지 않는다. 원본은 수정하지 않는다. 초기 검증 기준은 2026-11-27의 2228건(초611, 중673, 고944)이며 향후 개수 변화는 정상일 수 있다. 빈 성취수준은 창작하지 않는다. 충돌 중복은 사용자에게 명시하고 해당 기준 사용을 보류한다. 기존 단원에 적용한 기준의 원문이 바뀌면 기존 프로젝트의 스냅샷과 비교해 수정 제안을 제시하되 자동 덮어쓰지 않는다.
## 작업 순서
1. 입력 설계의 목표·개념·질문·평가·활동·차시 의도를 추출하고 불확실성을 표시한다. 기존 설계와 교육과정이 충돌하면 임의 수정하지 않는다. 학교급·과목·시간(초40/중45/고50분 기본)을 결정한다.
2. 관련 기준을 원본 그대로 인용하고 시트·행·조회 날짜를 기록한다. 코드만 알고 있을 때도 원문 확인을 우선한다. 전략은행은 단계·목적·출처에 맞게 선택한다.
3. 단원이라면 차시 간 발전 흐름과 평가 증거를 먼저 설계한다. 차시마다 성공기준과 활동 ID, 시간, 교사 발문, 예상 반응, 후속 발문, 준비물, 형성평가를 확정한다. 시간 총합을 확인한다.
4. references/production.md의 규칙에 따라 동일한 마스터 설계에서 요청 자료를 생성한다. 학생용 자료에 답안·교사 전용 설명을 노출하지 않는다. 실제 파일 요청은 사용 가능한 파일 제작 도구로 제작하며 미리보기만 제공하고 완료라고 하지 않는다.
5. references/quality.md의 검증 후 결과물과 검증 결과, 한계, 출처를 전달한다. 변경 시 영향받는 자료만 재생성하고 버전을 기록한다.
