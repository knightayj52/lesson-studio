# Lesson Studio

영쌤클래스의 교사용 수업 작업실입니다. 정적 파일을 GitHub Pages에서 서비스하며 별도 빌드가 필요하지 않습니다.

## 시작하기

Google로 로그인한 뒤 **프로젝트 개요 → 학교급별 수업 예시 열기**에서 초등·중등·고등 예시를 열 수 있습니다. 새 설계는 단원 개요·차시 구성·교육과정·자료 제작 순서로 편집합니다. 4단계 활동의 총 시간은 단원 설정과 일치해야 합니다. 첫 Drive 저장 이후 프로젝트는 편집 후 자동 저장됩니다. 출력 자료 보관을 선택하면 저장된 프로젝트와 연결된 별도 파일이 Drive에 추가됩니다.

## 연동

- Google Cloud 프로젝트는 `lesson-studio-516012`입니다. Drive API와 Sheets API, 기존 웹 OAuth 클라이언트의 GitHub Pages JavaScript 원본 설정을 사용합니다. 로그인은 기존 drive.file 범위를 사용하고, 교육과정 열람 시 spreadsheets.readonly 범위를 별도로 요청합니다. 시트에 대한 기존 열람 권한이 필요합니다.
- 교육과정 연결은 전체·전략은행·통합교과단원 탭을 읽습니다. 연결 중 탭을 다시 열거나 페이지에 돌아오거나 사용 중 5분이 지나면 갱신합니다. 적용한 행은 프로젝트에 보관하고 원문 변경을 표시합니다.
- AI는 선택 기능입니다. 사용자가 입력한 Gemini 키로 모델을 조회하고, 현재 선택한 차시의 초안을 요청합니다. 적용 전에 검토할 수 있습니다. 비밀 키는 커밋하거나 저장하지 않습니다.
- 첨부된 전문 스킬의 공통 원문은 `rules/`에 있습니다. AI 생성은 `rules/references/`의 두 파일을 직접 읽습니다.

## 파일과 검증

텍스트형 PDF·DOCX 본문·TXT·MD와 기존 프로젝트 JSON을 가져옵니다. PDF 스캔 OCR 및 그림·표 레이아웃 복원은 지원하지 않습니다. PDF에는 한글 글꼴을 포함하고 글꼴 범위를 벗어나는 자료는 이미지로 출력합니다. 브라우저 인쇄 및 PPTX 발표자 노트도 지원합니다.

`node --test tests/lesson-design.test.cjs`로 학교급별 활동 ID, 시간 합계, 자료 간 대응, 성취수준 원문, 가져온 목표 유지 여부를 검사합니다. OAuth 동의, 시트 접근, Drive 파일 보관, 실제 모델 사용 가능 여부는 운영 계정 설정에 따라 달라집니다.

## 포함한 라이브러리

JSZip 3.10.1, PptxGenJS 4.0.1, PDF.js 5.6.205, pdf-lib, @pdf-lib/fontkit의 배포 파일과 라이선스는 `vendor/`에 있습니다. PDF용 Lesson Studio Sans는 Noto Sans CJK KR의 한글·라틴·기호 글리프를 추출하고 TrueType으로 변환한 글꼴입니다. 배포 글꼴의 라이선스는 `vendor/lesson-sans-LICENSE.txt`에 포함되어 있습니다.
